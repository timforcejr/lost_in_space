# AI usage log: XAI Project 2 (Lost in Space; working title was Meaning Map)

Scope: this log covers Lost in Space, Tim Force's individual XAI project. "The NLP class project" or "the NLP project" in the entries below means the group NLP class project (see README "Where each part comes from"); that project's own AI use is not covered here. The only file taken from its tree is the vendored three.js 0.187.0 (third-party MIT code, unchanged).

This is the only place in the repository that records AI use. Files do not carry per-file AI notes. The About page of the live site gives a short statement that matches this file.

## Summary

- **Tool:** Claude Code (Anthropic), used by Tim Force from 2026-11-15 to 2026-11-23.
- **Models:** Claude Fable 5.2 (`claude-fable-5-2`), Claude Opus 5.5 (`claude-opus-5-5`) and Claude Sonnet 5.5 (`claude-sonnet-5-5`).
- **Roles the AI played:** planner, coder, runner (ran builds and benchmarks), researcher (literature check), author (README, talk, poster text) and reviewer (read-only checks). Each entry below says which model did which role.
- **Purpose:** to build the page, the build and evaluation scripts, the tests, the documents and the poster for XAI Project 2.
- **Human direction:** Tim Force set the question and scope, chose the name "Lost in Space", gave the instructions quoted in the entries, edited the poster and boundary-statement wording himself, and approved each push to GitHub.
- **Human review:** Tim has not read every code file line by line. The checks that stand behind the code are the tests listed in `README.md` ("Test"), the parity numbers in `eval/`, and the AI reviewer passes noted in the entries. Hindi and Chinese example sentences were written with AI help and have not been checked by a native speaker.
- **Not AI-generated:** the model weights and tokenizer files (public checkpoints), SIB-200 sentences, transformers.js, onnxruntime-web and three.js under `web/vendor/`, the MIT notice in `web/model/README.md`, and the course rubric.

## Entry 1: 2026-11-15, prototype v0 and plan

- **AI tool and version:** Claude Code, model Claude Fable 5.2 (`claude-fable-5-2`).

- **Prompt / intent summary:** Tim asked for a review of the XAI course book and the NLP class project, then a plan
  and a local version of a GitHub-hostable page that takes two sentences (English, Hindi, Chinese, Spanish), runs
  them through a transformer and an FC layer or autoencoder into a common embedding space, shows that space in an
  interactive 3D viewer, and uses Grad-CAM or other XAI tools; plus a poster later.
- **Third-party material (not AI-generated):** `paraphrase-multilingual-MiniLM-L12-v2` weights and tokenizer
  (Apache-2.0); SIB-200 sentences (CC BY-SA 4.0); transformers.js 3.7.5 with onnxruntime-web; three.js 0.187.0
  (copied from the NLP project's vendored, sha-pinned copy).
- **Verification done by the AI (evidence, not claims):**
  - Browser vs Python parity: identical token ids and per-layer similarities to 6 decimals on a probe pair.
  - `build/eval_attribution.py` asserts that the closed-form Grad-CAM equals the autograd Grad-CAM and that the
    pair split sums to the cosine score, on every one of its explanations.
  - `tests/grouping_parity.mjs`: the browser's word grouping equals the Python one on 4,022 sentences (0 mismatches).
  - `tests/check_heads.py`: 3D coordinates computed in the browser equal Python's for all three heads.
  - `tests/smoke.mjs` (headless Chrome): six sentence pairs, zero console errors, zero off-site requests, no
    horizontal scroll at 390 px. Screenshots in `tests/out/`.
  - All numbers quoted in the project plan are read from `eval/*.json`, which the scripts write.
- **Human oversight and modifications:** none yet. Tim has not reviewed this output. Hindi and Chinese example
  sentences were written by the AI and are not native-verified. Nothing is committed, pushed or deployed.
